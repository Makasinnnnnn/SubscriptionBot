# Восстановление БД

Проверяйте dump и восстановление сначала в отдельной тестовой БД. Скрипты `scripts/restore_db.sh` и `scripts/restore_db.ps1` заменяют объекты выбранной Compose-БД и требуют явного подтверждения. Они создают страховочную копию, проверяют dump, останавливают app, bot, ops и scheduler, затем запускают `pg_restore --single-transaction --exit-on-error`.

Если восстановление завершилось ошибкой, транзакция откатывается, а процессы записи остаются остановленными. Проверьте ошибку и состояние БД до ручного запуска сервисов. При успешном восстановлении сервисы запускаются снова. Скрипты не отключают внешних клиентов БД: остановите их отдельно на время обслуживания.

При наличии `.env.production` используются оба Compose-файла и параметры PostgreSQL из контейнера. Запускайте восстановление в том же проекте Compose, где создан backup. В Windows копирование dump проверяет exit code; ошибка копирования прерывает операцию.

Удаление Redis из Compose не меняет хранение FSM: aiogram использует память процесса, поэтому незавершённые диалоги сбрасываются при перезапуске. Масштабирование бота на несколько polling-процессов не поддерживается.
