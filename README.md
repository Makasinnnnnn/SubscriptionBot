# PropGate

Telegram-бот для продажи доступа к закрытым каналам. Автоматизирует оплату, выдачу приглашений, продление и отзыв подписок; ручные операции доступны администратору.

## Возможности

- Тарифы, скидочные промокоды и подписки с ограниченным сроком.
- Адаптеры Telegram Stars, Crypto Pay и ЮKassa; отдельный провайдер для тестов.
- Проверка уведомлений об оплате и защита от повторной выдачи доступа.
- Возвраты, напоминания и удаление из каналов после окончания подписки.
- Роли администраторов, ограничения по каналам и журнал операций.
- Выгрузки XLSX и обзорная веб-панель.

## Устройство

Python, aiogram, FastAPI, PostgreSQL, SQLAlchemy и Alembic. API принимает уведомления провайдеров, бот обрабатывает команды, scheduler проверяет сроки подписок. Общая логика находится в сервисах.

## Запуск

Нужны Docker и тестовый Telegram-бот с правами администратора в тестовом канале.

1. Скопируйте `config/local.example.txt` в локальный `.env` и заполните настройки.
2. Выполните `docker compose up --build`.
3. Проверьте `http://localhost:8000/health` и `/health/db`.
4. Добавьте тестовый канал и тариф через `/admin`.

Dev-payment не списывает деньги, но может выдавать реальные приглашения: используйте отдельный тестовый канал.

Для изолированных тестов: `python -m pip install ".[dev]"`, затем `python -m pytest -q`. Тесты используют подмены внешних провайдеров.

## Ограничения

- Нет общей постоянной очереди повторов внешних операций.
- Rate limit хранится в памяти одного процесса.
- Автотесты не подтверждают работу реальных платежей, DNS, Telegram и восстановления резервных копий.
- Система продуктовых метрик и когортных отчётов пока не реализована.
