# Политика обработки данных

PropGate обрабатывает только данные, необходимые для работы подписки: Telegram ID, username, имя профиля, сведения о выбранном тарифе, статус и идентификатор платежа, срок доступа и историю административных действий.

Бот не получает и не хранит данные банковской карты. Платёжные данные обрабатываются Telegram Stars или подключённой платёжной системой по её собственным правилам.

Данные используются для создания платежа, выдачи и отзыва доступа, поддержки пользователя, предотвращения повторной обработки операций и разрешения спорных ситуаций.

Доступ к административным данным предоставляется только уполномоченным администраторам. Секреты, пароли и полные платёжные payload не должны отображаться пользователям или записываться в открытые журналы.

Данные хранятся в течение срока, необходимого для работы сервиса, исполнения обязательств и учёта платежей. Пользователь может обратиться через /support по вопросу исправления или удаления данных, если их хранение не требуется по закону или для разрешения платёжного спора.

Перед запуском для реальных клиентов этот текст необходимо проверить и дополнить сведениями об операторе данных и применимом законодательстве.
